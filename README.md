# Job Tracker Pro

Трекер поиска работы с системой анализа прогресса и двумя режимами отображения: публичным (для портфолио) и приватным (для личной работы).

[![Streamlit App](https://job-tracker-pro-kct92fmxvvk9iyazspdqcn.streamlit.app/)](https://[твой-субдомен].streamlit.app)

---

## О проекте

Это не просто CRUD-трекер вакансий. Это инструмент, который я использую сам и который одновременно служит демонстрацией моего подхода к работе с данными:

- **Системность.** Каждый отклик фиксируется, статус обновляется, причины отказов анализируются.
- **Саморефлексия.** После каждого отказа я записываю выводы — что не хватило, что изучить.
- **Прозрачность.** Публичный режим показывает процесс поиска работы, скрывая названия компаний и личные заметки.

Проект задуман так, чтобы его можно было открыть потенциальному работодателю: он видит не количество отказов, а аналитику, прогресс навыков и умение работать с данными.

## Возможности

### Управление вакансиями
- Полный CRUD: добавление, просмотр, редактирование, удаление.
- Поля: компания, должность, ссылка, статус, дата отклика, причина отказа, выводы, заметки.
- Статусы: «В планах», «Откликнулся», «Собеседование», «Тестовое задание», «Оффер», «Отказ».
- По умолчанию в таблице видны только активные статусы; завершённые включаются чекбоксом.

### Два режима отображения
- **Публичный режим** (по умолчанию): показывает только те вакансии, которые я отметил как публичные. Названия компаний маскируются («Компания 1», «Компания 2»), ссылки и личные заметки скрыты.
- **Полный доступ** (по паролю): все данные, аналитика по отказам, управление видимостью записей.

### Аналитика
- Метрики: всего откликов, в работе, офферов.
- Воронка успешности: отклики → собеседования → тестовые → офферы.
- Динамика откликов по дням.
- Топ-5 причин отказов (только в полном доступе).
- Тепловая карта активности за год (как в GitHub).
- Streak-трекер: сколько дней подряд я делаю что-то для поиска работы.

### Прогресс и рефлексия
- Таблица «Уроки из отказов» — выводы по каждой неудаче.
- Блок «Мой прогресс» — курсы, улучшенные навыки, пет-проекты.
- Автогенерируемое резюме по итогам поиска.
